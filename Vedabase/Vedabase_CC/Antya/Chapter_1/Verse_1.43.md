# CC Antya 1.43

**Bengali:**

svapna dekhi’ rūpa-gosāñi karilā vicāra
satyabhāmāra ājñā — pṛthak nāṭaka karibāra

**Transliteration:**

svapna dekhi’ — after dreaming; rūpa-gosāñi — Rūpa Gosvāmī; karilā vicāra — considered; satyabhāmāra ājñā — the order of Śrīmatī Satyabhāmā; pṛthak nāṭaka karibāra — to write a separate drama.

**Synonyms:**

Synonyms
svapna dekhi’ — after dreaming; rūpa-gosāñi — Rūpa Gosvāmī; karilā vicāra — considered; satyabhāmāra ājñā — the order of Śrīmatī Satyabhāmā; pṛthak nāṭaka karibāra — to write a separate drama.

**Translation:**

Translation
After having that dream, Śrīla Rūpa Gosvāmī considered, “It is the order of Satyabhāmā that I write a separate drama for her.
